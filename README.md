# Saving Solutions Group — website & digital insurance platform

Next.js 16 · Tailwind v4 · GSAP · Lenis · React Three Fiber. Static export.

```bash
npm run dev -- -p 3010
```

- Content: `src/lib/data.ts` (products, nav, contact), `src/lib/questions.ts` (conditional quote logic)
- Intake webhook: set `NEXT_PUBLIC_INTAKE_WEBHOOK` at build time (GoHighLevel / Zapier / API gateway)
- Pending photography: `assets/HIGGSFIELD-QUEUE.md` (drop files into `public/media/`)
